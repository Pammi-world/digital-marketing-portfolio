# Digital Marketing Portfolio

A modern portfolio website for digital marketing services built with Express + EJS.

## Tech Stack

- **Backend:** Express.js
- **Frontend:** HTML, CSS, JavaScript
- **Templating:** EJS
- **Style:** Modern dark theme with sleek animations

## Design

- **Primary:** Dark Red (#8B0000)
- **Accent:** Cream (#FFFDD0)
- **Background:** Dark/Deep Red or Black
- **Text:** Cream/White

## Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
